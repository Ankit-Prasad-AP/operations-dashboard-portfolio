# Portfolio Notes

This public dashboard intentionally prioritizes visual storytelling and recruiter readability while preserving the core planning concepts from the production workflow.

The demo is not a clone of an internal system. It is a clean, synthetic showcase that demonstrates:

1. how production is applied against demand,
2. how negative-balance-through-date logic identifies risk,
3. how blank pick dates can be handled with a ship-date fallback,
4. how noisy placeholder rows can be excluded, and
5. how operational metadata improves planner decisions.

No real company, customer, item, vendor, workbook, or source-system identifiers are included.
