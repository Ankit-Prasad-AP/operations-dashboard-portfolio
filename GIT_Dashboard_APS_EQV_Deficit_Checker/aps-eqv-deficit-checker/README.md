# APS EQV Deficit Checker — Portfolio Demo

This is a sanitized, recruiter-facing demo of a manufacturing planning dashboard. It shows how live product availability, equivalent-case factors, and scheduled production timing can be combined into a clear seven-day risk cockpit.

## What it demonstrates

- Equivalent-case deficit calculations.
- Safe / Review / Not Safe status logic.
- Production timing visibility by week bucket and schedule.
- KPI cards, charts, timeline, and exception table designed for fast operational review.
- A polished demo flow that can be understood without access to employer data.

## How to use locally

Open `index.html` in a browser and click **Load Demo Data**.

No external data files, APIs, CDNs, or network calls are required.

## Confidentiality

This folder uses synthetic item codes, generalized business rules, and fabricated quantities. It does not contain real employer workbooks, customer names, supplier names, material codes, or production data.
