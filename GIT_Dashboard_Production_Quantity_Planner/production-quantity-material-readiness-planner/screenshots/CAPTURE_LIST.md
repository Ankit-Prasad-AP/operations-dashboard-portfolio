# Screenshot capture list

No dashboard PNGs are included in this build because the available browser renderer did not complete screenshot capture reliably. Do not treat this as a visual-browser validation.

When capturing locally, load the synthetic demo and use these states:

1. `01-production-plan.png` — Demo data loaded on Production Plan. Show the hero, KPI cards, weekly production cadence, and coverage-by-product panel. Suggested viewport: 1440×1000.
2. `02-material-readiness.png` — Demo data loaded with Material Readiness analysis run. Show readiness KPIs, execution-readiness donut, action queue, risk-by-category bars, and inbound-supply timeline. Suggested viewport: 1440×1000.
3. `03-short-materials.png` — Material Readiness after analysis, scrolled to Under / Short Materials with decision-first exceptions visible. Suggested viewport: 1440×1000.

Before committing, visually inspect every capture for synthetic-only names/codes, clean alignment, legible text, and absence of browser/local-path artifacts.
