      2. Planning Model

      01Whole-load rule

      Every tanker is assigned to one destination. Unused cream stays there and carries forward.

      02Continuous consumption

      Cream is consumed from run start through finish; the next tanker is triggered only when a site balance would run out.

      03No-short priority

      Dispatches are sequenced by the earliest projected site shortage so the plan protects every destination.

      04Receiving deadline

      The tanker must be available at central receiving before the projected site need by the configured lead time.

      Current scenario assumption: opening Normal Cream is 0 lb at each destination. Previously committed or in-transit tankers are intentionally reserved for a future version. Organic cream remains separate; oat materials are outside this dashboard.

      How It Works

      1. Read scheduled production by line, quantity, start time, finish time, and cream-per-case requirement.
      2. Split runs across calendar days when production crosses midnight so daily consumption is auditable.
      3. Combine production lines mapped to a shared destination into one site balance while keeping the other configured destinations independent.
      4. Consume cream continuously through each run instead of charging the full requirement at run start.
      5. When a site would run out, assign one complete tanker to that destination; unused cream remains at that site.
      6. Move each tanker deadline earlier by the configured receiving lead so the load is available at the central receiving point before production needs it.
      7. Compare aggregate tanker equivalents with the physical site plan to expose extra loads caused by non-transferable site inventory.
