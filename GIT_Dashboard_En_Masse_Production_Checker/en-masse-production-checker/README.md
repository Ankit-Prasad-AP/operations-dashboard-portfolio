# Production Update Decision Cockpit

A polished, recruiter-facing GitHub demo of a manufacturing production update checker. The demo shows how a planner can compare scheduled production rows with recent production history, identify rows needing review, select production entries, reduce scheduled cases, mark rows finished, and export a case-only update decision file.

## What this demonstrates

- Manufacturing production schedule review
- Current-week and prior-week context
- Production history matching by item
- Case reduction and finished-row decisions
- Safe case-only update thinking
- KPI cards, risk mix, production trend, line-load bars, schedule cadence, and a polished decision table

## Public demo data

All data is synthetic. No real employer, customer, supplier, item, workbook, plant, production lot, or operational identifier is included.

## How to use

1. Open `index.html`.
2. Click **Load Demo Data**.
3. Review the KPI cards and visual analytics.
4. Filter by schedule or search for an item.
5. Click an item code to open the floating detail view.
6. Select production history entries and apply the selected quantity to reduce current-week cases.
7. Mark rows finished when appropriate.
8. Export the sanitized demo CSV.

## Portfolio note

This version is intentionally presentation-focused. It preserves the core business story of the production workflow while prioritizing visual clarity, recruiter readability, and operational storytelling.
