# Synthetic sample inputs

These files contain deterministic synthetic manufacturing data used by the public demo. They are safe for the portfolio repository and contain no employer, customer, supplier, item, material, PO, or SO identifiers from a real operation.

- `production_plan.csv` — forecast, finished-goods inventory, open-order context, and planned weekly production.
- `bom.csv` — packaging and batching quantity-per-case requirements.
- `material_inventory.csv` — system inventory plus an example validated physical can count and a non-blocking utility.
- `purchase_orders.csv` — dated synthetic purchase-order receipts used for run-date recommendations.
