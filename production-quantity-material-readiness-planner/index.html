What This Does

This planner connects a weekly production plan to the materials required to execute it. It combines forecast context, finished-goods inventory, packaging and batching requirements, on-hand material, physical counts when available, and dated purchase orders. The result is a concise decision view showing whether each planned run is covered, whether it should move later in the week, or whether new supply is required.

How It Works

  1. Start with the weekly production quantities entered on Page 1.
  2. Convert each planned run into packaging and batching requirements using quantity-per-case data.
  3. Use physical can inventory when a validated physical count exists; otherwise use system inventory.
  4. Add purchase orders by arrival date; a PO dated on the production day is treated as available before the run.
  5. For shared material on the same date, allocate available supply from the largest requirement to the smallest.
  6. If the planned date is short, search later PO dates in that week and recommend the earliest covered date.
  7. If no sufficient future PO exists, flag the run for new supply. Non-stock utilities remain visible but do not block production readiness.
